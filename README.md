# Jankenpo

Versão web do jogo, escrita em PHP. Simples, sem camada de modelo, mas com templates.

Sobre o método usado: fiquei na dúvida se a escolha do jogador deveria viajar no corpo da requisição. Como não estou alterando nada no servidor, o envio é feito por POST — a imagem abaixo ilustra a diferença entre os métodos.
